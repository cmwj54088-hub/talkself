# 自言

完全离线的 Android 笔记与待办应用，以项目组织聊天式记录。无需账号，不申请联网权限。

项目记录：[当前状态与已确认事项](docs/PROJECT_STATUS.md) · [更新记录](docs/CHANGELOG.md)。

## 功能

- 记录文字、图文、图片、视频及通用文件卡片，支持全屏选择多个目标项目后统一转发，各副本可独立编辑。
- 接收其他安卓应用通过系统分享发送的文字、链接、图片、视频和文档等附件，预览并选择目标项目后确认保存。
- 多页手写，保留原始笔迹，可继续编辑。
- 待办支持图片、独立的截止日期与系统提醒闹钟；项目待办栏只显示未完成事项。
- 按关键词、项目、内容类型和创建日期搜索，点击结果定位原记录。
- 首页滑动切换项目、待办和设置，底栏固定。
- 导出完整 JSON 备份，包含附件、手写、模板和草稿，可在其他设备导入。

## 使用

支持 Android 8.0 及以上。同签名 APK 可覆盖升级，更新前建议导出备份。

在其他应用选择系统「分享」或「其他应用打开」，再选择「自言」。分享文字可在保存前编辑，单张／多张图片和视频可预览，文档显示文件卡片；确认后附件复制到应用内部，并进入完整 JSON 备份。取消不会改变已有笔记或输入草稿。连续分享会依次等待确认，未确认的分享暂存于应用内部，重新打开后仍可处理。

微信聊天：通过微信可用的「Open／打开」等系统分享入口选择「自言」，接收包含 Chat history.txt 的聊天 ZIP。合并发送按“发送者＋原时间”标题逐条导入；逐条发送按明确的 `·` 条目标记导入，来源没有姓名／时间时显示未知，不推测补齐。预览可核对总数、逐条编辑并切换格式；无法识别或附件无法关联时，需要明确确认保留整份原文。正文内部空行不会单独拆成消息，同名连续发送也分别保留；合并正文里的普通 `·` 项目符号不算新消息，逐条发送遇到歧义会要求核对条数并确认。图片、视频与文件归属原消息，来源信息贯通编辑、搜索、转发、Markdown 和完整备份。

聊天没有五万字总上限。当前资源限制为：每次一个 ZIP，压缩包及单附件 200 MB，解压总量 512 MB，最多 256 个 ZIP 条目，UTF-8 正文 8 MB、20000 条消息；单条原消息最多 200 万字，不按字数拆成多条。预览每页 20 条摘要，聊天默认显示最新 60 条，长图文可打开完整排版及图片。明确缩进的 `[Chat History]` 内层聊天保留为可打开的卡片，最多 8 层；20000 条限制包含内层。缺失引用、加密或损坏聊天 ZIP 整批拒绝，不截断或保存半批。小程序私有卡片、微信账号及聊天数据库不在支持范围。

DOCX、PDF、PPTX、ZIP 及未知格式作为原文件卡片保留，显示文件名、类型和大小，可另存，或选择手机上其他应用打开；自言不解析文档内容。外部应用仅获本次文件的临时只读授权，没有可用应用时会提示。普通 ZIP 附件不递归解压，聊天卡片内容来自正文的明确结构。文件、内层聊天及媒体一起进入完整备份和多项目转发。

数据仅保存在本机。卸载或清除应用数据会删除记录；导入备份会替换当前数据，不会合并。当前不支持云同步或加密，单附件上限 200 MB，备份导入上限 512 MB。

长按笔记打开操作菜单，通过「选择部分文字」复制局部内容；双击或手机双触文字／图文／待办气泡可打开全屏编辑器。消息流的三点按钮已去掉，操作保留在长按菜单。待办也出现在项目消息流，直接引用原待办；点完成控件加删除线，再点恢复。历史待办自动呈现，无需重新导入；设置可关闭消息流待办气泡，不删除任务、不改变待办栏和全局待办。转发到其他项目会创建独立、未完成的新待办，保留原任务与截止日期，提醒不自动启用。待办栏展开／收起会保持底部或历史阅读位置。输入区主按钮始终可见，空内容时禁用；笔记／待办共用每个项目的一份草稿，保存待办后自动回到发送模式。模板的新建和编辑使用全屏页面。

提醒与截止日期独立：待办行、待办菜单或完整编辑页可选择提醒时间并打开系统闹钟，请在系统时钟确认响铃日期、重复和启用状态。单独保存提醒时间不会启用闹钟，完成／删除待办、清除提醒时间或导入备份也不会关闭或重建系统闹钟。备份恢复提醒时间；系统闹钟由系统时钟管理。没有可用时钟应用时会提示，待办内容仍保留。

## 本地预览

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

在浏览器打开 `http://127.0.0.1:4173`。前端源文件位于 `dist/`，Android 容器源码位于 `android/app/src/`。

## 构建 APK

需要 Python 3.10+、JDK 17+、Android SDK Platform 35 和 Build Tools 35.0.0。

```powershell
$env:ANDROID_SDK_ROOT='C:\Android\Sdk'
$env:ZIYAN_JAVA_COMPILER='javac'
python -X utf8 android/build.py
```

将 SDK 路径替换为实际目录，安装包输出到 `releases/`。发布签名不随仓库提供；覆盖升级必须沿用原签名。独立构建及 Linux 环境说明见 [Android 构建说明](android/README.md)。

## 测试

启动本地预览服务后，安装 `dev-requirements.txt` 中的依赖，运行：

```sh
python tests/check_v5.py
python tests/check_v5_edges.py
python tests/check_wechat_archive.py
python tests/check_interactions.py
```

安装 Node.js 与 Playwright 后，可运行 `node tests/check_records.cjs`、`node tests/check_home_swipes.cjs` 和 `node tests/check_shares.cjs`、`node tests/check_wechat_import.cjs`、`node tests/check_chat_task_stream.cjs`、`node tests/check_followup.cjs` 检查转发、搜索、触摸滑动及分享接收。分享测试使用打包后的界面和桥接模拟，需要先构建 APK。微信测试先运行 `python tests/check_wechat_archive.py` 生成虚构测试夹具，再运行 `node tests/check_wechat_import.cjs`。真实样本仅在显式传入 `--include-local-evidence` 时读取；本地证据和生成夹具均不提交 Git。测试可通过 `CHROME_PATH` 指定 Chrome 浏览器路径。

APK 构建后运行 `python tests/check_native_adapter.py` 检查内置资源和原生桥接。浏览器测试不替代安卓真机验证。

输入区展开复用笔记全屏编辑器，普通消息、待办输入及已有待办编辑均覆盖；返回保留共用草稿、图片和待办日期偏好，不发送。含格式／图片的草稿从原全屏编辑器继续改，紧凑输入区不再覆盖图文排版；底部发送保留原格式和图片位置。每行保存一条待办，图片附在第一条。单次安卓复制上限 20 万字，超长内容可局部选择或导出。项目及分享预览可导出 Markdown（附件随 ZIP）；链接卡片由外部浏览器选择器打开。

前批功能：全局待办可按单项目筛选，顶部花园表示当前范围已完成比例，双击底栏项目可循环定位待办角标。花园植物可随摇动在盒内移动、摆动并碰撞边界，受设备传感器与减少动态效果设置影响。

应用内日期提醒需首次主动启用并授予通知与精确闹钟权限，以通知发声，受静音、勿扰及通知渠道设置影响。完成、删除或清除会取消应用内预约；重启后恢复未来提醒。系统时钟入口仍独立管理。仅保存日期与时间不代表预约。实际手机响铃及厂商后台行为尚待真机验收。
