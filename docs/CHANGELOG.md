## 0.12.0 · 2026-11-02 · 通用文件与后续交互修正（部分验收）

- 聊天 ZIP 保留 DOCX／PDF／PPTX／ZIP／未知格式附件，以文件卡片显示名称、类型和大小；支持另存和外部应用只读打开，不解析文档内容。
- 识别明确缩进的内层聊天卡片，预览及保存后可打开；来源、层级、文件和图片贯通原子转发、Markdown 及完整 JSON 恢复。
- 合并导入只按带时间标题的发送动作分界，正文项目符号保留；逐条标记歧义要求确认。
- 待办气泡支持双击／双触全屏编辑；设置可开关显示，任务本体与其他入口保留。去掉消息流三点按钮，保留长按操作；统一正文行距。
- 富文本草稿继续使用原全屏编辑器，避免紧凑区覆盖格式和图片位置；长图文提供带图片的完整查看。
- 花园增加盒内位移、摆动与边界／植物碰撞，保持减少动态效果和前台限制。
- 沿用原签名和既有四项权限，无 INTERNET。用户反馈除微信导入解析仍有问题外，其余本轮功能正常，内层聊天可打开；解析问题、备份变小调查及图片拖动／缩放暂缓。相关检查通过不代替所有真机条件，本批未合并／推送。

## 0.11.0 · 2026-11-01 · 逐条聊天与待办消息流（历史候选版）

- 区分微信合并／逐条正文，按原发送动作导入；独立显示来源姓名与原时间，缺失时显示未知，同名／同时间消息不合并。图文视频保持同条关联，未知结构须确认原文回退。
- 解除聊天总正文五万字上限，采用 8MB UTF-8／20000 条／单条 200 万字资源界限；原生分块正文传输、逐条预览与长消息折叠，导入保持原子事务。
- 普通消息及待办输入展开复用现有全屏编辑组件，返回保留草稿、图片及待办偏好；保存不重复发送。
- 新旧待办直接融合消息流，同一任务的完成／删除线、待办栏、全局列表、花园及提醒同步；不生成第二份消息。
- 待办支持搜索／最近项目／多目标转发；目标为独立未完成待办，附件和截止日期保留，提醒不自动启用，失败整批回滚。
- 新来源字段与关联视频贯通编辑、搜索、转发、Markdown 和 v3 JSON 备份。无新增权限或网络依赖。真机与用户验收尚未完成。
