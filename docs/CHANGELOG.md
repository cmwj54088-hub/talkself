# 更新记录

维护日期：2026-11-01。仅记录已实现的变更；已确认约定和待澄清需求见 [项目状态](PROJECT_STATUS.md)。

## 0.9.1 · 待办栏定位修正

- 展开、收起待办栏时保持历史文字的屏幕位置；在底部阅读时保持底部。
- 主动滚动时交还控制，处理图片延迟加载及短视口。
- 保留 0.9.0 的微信聊天 ZIP 导入能力。
- 交互回归、打包资源、原生桥接、签名及对齐检查通过；真机复测尚未形成完整验收记录。

## 0.9.0 · 微信聊天 ZIP 导入

- 接收包含 `Chat history.txt` 的微信聊天 ZIP，预览、编辑正文、选择项目后确认保存。
- 正文保留来源中已有的发送者和时间；图片按引用位置插入，视频作为独立附件。
- 附件进入本地存储及完整 JSON 备份；损坏、缺失引用、越界路径和超限输入整批拒绝。
- 移除临时分享诊断入口。

## 0.8.0 · 交互与编辑改进

- 长按弹菜单并抑制默认选字；明确的文字选择入口仍可选字。
- 转发改为全屏选择器，支持搜索、最近项目及多个目标的一次性原子保存。
- 双击／双触文字和图文消息进入全屏编辑，保留原 ID、创建时间。
- 优化笔记及模板全屏编辑；输入区按钮常显，空内容禁用，切换模式保留草稿，保存待办后回到笔记模式。
- 提醒时间与截止日期分开，提供跳转系统时钟设置闹钟的入口；保存时间不等于已开启闹钟。

## 0.7.1 · 临时分享诊断

- 增加分享格式诊断入口，供本地定位接收问题。此入口已在 0.9.0 移除。

## 0.7.0 · 安卓分享接收

- 接收系统分享／其他应用打开提供的文字、链接、图片和视频。
- 冷启动与运行中接收均先预览；确认保存、取消、队列、临时附件持久化及失败重试保护原有草稿。

## 0.6.0 · 转发、搜索与待办

- 增加跨项目独立转发、组合搜索及原记录定位。
- 项目待办栏只显示未完成事项，完成记录保留在全局待办。
- 修复真实触摸首页滑动，切换、回弹期间底栏固定。

## 代码整合与隐私整理

- 2026-10-31：两组开发成果统一提交为 `7c6bcea`，合入并推送 `main`。
- 排除本地聊天样本、诊断资料、签名、备份、安装包及构建输出，保留本地原件。
- 微信解析测试默认生成虚构样本；读取本地真实证据需要显式指定 `--include-local-evidence`。
