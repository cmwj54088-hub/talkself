## 已确认的产品约定

- Android 优先，完全离线，无账号、云同步、广告、统计或 AI 服务；不申请联网权限。
- 浅色模式本轮先不做；录音、转写等未授权功能不自动加入。
- 首页在项目、待办、设置之间滑动，底栏固定。
- 项目待办栏只显示未完成事项；全局待办保留已完成记录。新旧待办直接融合项目消息流，不复制数据；气泡点完成／恢复同步各入口。
- 长按使用操作菜单；局部文字选择通过明确入口进行。文字／图文可双击进入全屏编辑。
- 笔记与待办共用每个项目的一份草稿；切换不丢字，成功保存待办后返回笔记模式。
- 跨项目转发保留原记录，为目标项目创建独立副本；多个目标的写入原子完成。待办副本是新 ID 的未完成待办，截止日期与独立附件保留，提醒不自动启用。
- 完整 JSON 备份包含附件和可编辑手写；导入会替换当前数据，不自动合并。
- 当前提醒时间独立于截止日期。现有系统时钟入口需要用户确认；不能把“已保存提醒时间”说成“已开启闹钟”。

上述为当前已约定行为，具体字段、边界和兼容要求维护在 `REQUIREMENTS.md`。后续确认新行为时先更新相应条目，再实施和验证，不在两份文件复制维护所有细节。
