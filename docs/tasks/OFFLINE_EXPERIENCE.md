## 接口、依赖和边界

- N01／N02 复用同一份项目草稿及现有全屏编辑器，不另造一份难以同步的草稿；切换、取消和返回保持用户输入。手机键盘行为需真机测试。
- N04 先检查现有系统时钟桥接。日期时间采用本地时区，旧数据只有 HH:mm 时保留兼容，不静默补出虚假提醒日期。Android 系统时钟若无法按指定日历日期预约，提交具体能力证据与可行选项给用户决策；先完成其余独立项，不擅自追加通知／精确闹钟权限，不把未实现能力写为完成。
- N06 仅允许 http/https，经原生桥接 ACTION_VIEW + 显式 chooser 打开浏览器处理器；不要调用短信、电话、自定义 scheme 或在有 Java 桥接的笔记 WebView 内加载远端网页。自言保留无 INTERNET、无后台请求；浏览器联网属于用户主动离开应用访问网站。取消选择不能丢字。
- 链接卡片从现有文本识别网址，离线显示域名／网址及已有文本，不下载标题、封面、图标或远程字体；按纯文本安全处理，避免 HTML 注入。浏览器版回退采用用户点击打开新页，不伪称已测试 Android 选择器。
- N07／N08 共用导出格式与附件命名，UTF-8 Markdown；附件名称防路径穿越／冲突，视频可作为相对链接，手写可导出可读预览。特殊富文本降级时保留可读正文并注明限制。缺失或损坏附件不能静默丢掉后报告成功。保留现有完整 JSON 备份能力，不把 Markdown 当成完整恢复格式。
- N08 不访问微信数据库，不绕过微信分享限制；若微信只交付摘要／链接，只能导出这些实际收到的内容。复用当前已支持的聊天 ZIP 解析；未收到的聊天记录不可凭空提取。预览内编辑的正文应反映在导出内容里，取消导出不影响原草稿。
- N09／N10 口径：选择项目时取该项目，否则取所有项目；花园分母包含该范围内完成与未完成待办，不受状态筛选按钮影响。零待办显示 0 项和空园，百分比显示“暂无待办”；新增未完成可降低比例，取消完成也会减少繁密程度。
- N11 默认定位列表顺序中第一个带角标项目；后续双击循环到下一个，定位后短暂强调。复用现有角标含义，不为此引入新的“未读”数据模型。
- 无既有设计细节时，以上普通交互默认由执行者实现并记录；若代码核对发现与用户已确认规则冲突，先报告真实冲突再改契约。
