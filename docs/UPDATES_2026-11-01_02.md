# 自言近两日更新汇总

统计范围：2026 年 11 月 1—2 日；截至 11 月 2 日本次整理。主要覆盖 0.10.0 → 0.12.0。

这两天主要完善了全屏记录、待办消息流、聊天与文件导入、导出，以及待办花园。应用继续离线运行，未增加联网权限，浅色模式未开展。

**当前结论：0.12.0 部分验收通过。微信导入解析仍有问题，暂缓处理；其他本轮功能反馈正常，内层聊天可以打开。**

## 记录与编辑

- 普通消息和待办输入的“展开”复用笔记的全屏编辑界面；已有待办也可进入全屏编辑。
- 返回、切换笔记／待办时保留草稿、图片及日期偏好；保存待办后回到笔记模式，避免重复发送。
- 切换按钮简化，发送／保存按钮及短视口布局得到修正。
- 富文本草稿从原全屏编辑器继续编辑，保留加粗与内联图片位置，避免返回底部输入后覆盖排版。
- 长图文可以完整查看，包含图片和附件；统一消息、待办与编辑界面的正文行距和显式换行。
- 消息流移除三点按钮，保留长按菜单；待办气泡支持双击／双触进入全屏编辑，完成框仅切换完成状态。

## 待办、提醒与花园

- 新旧待办直接出现在项目消息流，沿用原任务 ID、创建时间与完成状态，不另复制一份数据，也不需要重新导入历史待办。
- 点击完成后显示删除线；再次点击恢复未完成。消息流、项目待办栏、全局待办和完成率统计同步。
- 设置中可关闭／恢复待办气泡显示，关闭不会删除任务，也不影响其他待办入口。
- 待办支持跨项目、多目标转发。目标是独立新待办，默认未完成；保留正文、附件和截止日期，不自动启用提醒，源任务保持不变。
- 全局待办可搜索并选择单个项目筛选，与完成状态筛选组合使用。
- 提醒日期与时间独立于截止日期；增加应用内单次日期提醒、完成／删除后取消以及重启恢复未来预约的实现。
- 通知、精确闹钟授权、通知声音渠道及预约状态集中到设置中处理；手机实际响铃及厂商后台行为仍有未独立实测的条件。
- 顶部花园以繁密程度呈现完成比例；按当前项目范围统计，状态筛选不改变分母。增加随手机运动的摇摆、位移和边界／植物碰撞，支持减少动态效果及前后台控制。

## 微信聊天与附件导入

- 从“整份聊天塞进一篇笔记”改为识别原发送动作，生成独立消息；区分 one by one 与 combine，显示来源中实际提供的用户名和原时间。
- 解除整份聊天五万字的硬限制，增加正文分块传输、预览分页、长消息折叠和原子保存。当前策略上限为正文 8MB UTF-8、20000 条消息；已测规模与策略上限不同，不代表满上限真机压力测试通过。
- 增加明确缩进的内层聊天卡片，预览与保存后都可打开；来源、层级及媒体关联进入转发、导出和备份。
- 聊天 ZIP 可保留 DOCX、PDF、PPTX、ZIP 及未知格式文件，显示文件名、类型和大小；支持另存及交给外部应用只读打开。自言不解析文档内容，也不递归解压普通 ZIP 附件。
- 对逐条标记与正文项目符号的歧义增加确认处理；未知来源不伪造姓名、时间或消息边界。

**尚未解决：用户实际使用时，微信导入解析仍有问题。** 内层聊天“能打开”已获认可，不代表消息拆分、数量、归属或所有微信格式均正确。现有样本和自动化检查通过不覆盖本次用户反馈；用户要求先保持现状，未继续修复。

## 首页、链接、导出与数据保护

- 首页采用三层深色灰度，恢复连续项目列表和头像右侧细分隔线；双击底栏“项目”可定位带角标的项目。
- 链接以紧凑卡片显示，避免重复展示长网址；点击弹出外部浏览器选择器，由浏览器联网访问，返回自言继续记录。自言不后台抓取网页标题、封面或图标。
- 整个项目和分享预览支持 Markdown 导出；有附件时输出 `.md + 附件目录` 的 ZIP，使用相对引用。
- 来源信息、嵌套聊天、视频及通用文件贯通转发、Markdown 和完整 JSON 备份恢复；多目标写入及失败回滚有相关检查。
- 完整恢复仍使用 JSON，Markdown 不是完整恢复备份；原升级签名与包名保持不变，私人样本、密钥及安装包继续排除在 GitHub 外。

- 建立并补充更新记录、项目状态、分批任务、交付与验收记录；工具路径和 PowerShell 构建／测试命令统一放入 [工具链说明](TOOLCHAIN.md)。
